# RKAV kleedkamerplanner — eerste prototype

Start lokaal met Python 3.11+:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Upload daarna het aangeleverde wedstrijdschema als Excelbestand.

**Belangrijk:** dit is een experimentele, heuristische planner, geen definitieve clubplanning. Het systeem gebruikt de kamerverdeling uit `Blad2` en instelbare wedstrijd- en omkleedtijden. Controleer de wedstrijdduur en bijzondere afspraken. Het garandeert geen optimale oplossing. Scheidsrechters, formele conflicthercontrole na handmatige wijzigingen en sommige uitzonderingen zijn nog niet ingebouwd.
